# Postism — 過程の記録

Postism(雑に書いたメモを投げると、裏でAIが整理してくれる個人用アプリ)を作る過程と意思決定の記録です。
マネジメントやプロダクトの視点を鍛えるための個人プロジェクトとして、公開しながら進めています。

## リポジトリ構成

| リポジトリ | 役割 | 公開範囲 |
| --- | --- | --- |
| [ne0san/postism](https://github.com/ne0san/postism) | ソースコードと仕様 | 公開の方針(コントリビュート可) |
| ne0san/postism-process | 過程と意思決定の記録(このリポジトリ) | 公開 |
| postism-journey | 生の使用日誌 | 非公開 |

## このリポジトリの中身

- [`STATUS.md`](STATUS.md) — 現在地(いまどこ、次は何、未決)
- [`decisions/`](decisions/) — 意思決定ログ(1決定1ファイル、追記型)
- `retros/` — ふりかえり
- `research/` — 競合調査など

## 読み方

1. まず [`STATUS.md`](STATUS.md) で現在地を見る
2. 次に [`decisions/README.md`](decisions/README.md) で決定の一覧と運用ルールを見る
