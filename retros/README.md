# ふりかえりの進め方

## KPTの項目はオーナーが挙げる

- Keep / Problem / Try の項目は、オーナーが自分で書く。
  自分で書いたものでないと、守る気にならないため。
- Claudeは項目を追加・代筆しない。やるのは次の3つだけ。
  - 聞き返す(それはどういうことか)
  - 決定ログやSTATUSとの食い違いを指摘する
  - オーナーの言葉のまま、ファイルに整える(オーナーが指示したとき)
- Tryは、オーナーが次の区切りで実際にやると決めたものだけ残す。

## 区切りごとに残すもの

- KPT
- バックログのスナップショット(選んだIssue、終わったものと落としたものとその理由、Issueへのリンク)([0012](../decisions/0012-templates-and-dod.md))
