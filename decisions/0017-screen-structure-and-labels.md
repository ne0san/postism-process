# 画面構成と表記: 下タブ4つ、画面タイトル、「記録」への改名、マーカーの形

- 状態: 提案
- 決定日: (未承認)
- 決定者: オーナー

## 背景

11/6〜11/9のデザイン見本で、一覧と種類別の画面の構成を、iOSのネイティブ前提で組んだ。[0013](0013-design-principles.md) の未決事項「種類ごとのマーカーの形(色以外の見せわけ方を含む)」も、ここで形にした。

## 検討した選択肢

- 種類ごとの区切りで1画面にまとめる(最初の見本)
- 一覧(全種類を日付順)と、種類別の画面を分けて、下のタブで切り替える

(オーナーは、下のタブで切り替える形を指示した)

## 決定

(提案。承認されるまで決定ではない)

- 画面は、「一覧」と、種類別の3画面(ToDo / 疑問 / 記録)にする。下のタブバーで切り替える。
- タブバーは、最近のiOS標準風に、丸角の半透明のバーとして画面の下に浮かせる。
- 左上の画面タイトルは、一覧が「Posts」、他の画面はその画面の名前(疑問なら「疑問」)にする。アプリ名(Postism)は画面に出さない。
- 種類の名前は「ToDo / 疑問 / 記録」にする。「気づき」は「記録」に変える。
- マーカーの形は、ToDoが四角(解決するとチェック入り)、疑問が丸に「?」、記録が菱形にする。タブのアイコンも同じ形を使う(ToDoはチェック入りの四角、一覧は3本線)。

## 議論での論点

(以下はClaudeの提案を含む)

- アプリ名を出さない理由は、TodoistもNotionも標準の画面で自分のアプリ名を主張していないから(オーナー)。
- 「気づき」を「記録」にするのは、ToDoと疑問以外が入る一覧なので、汎用的な名前にしたいから(オーナー)。種類の追加や削減は、この決定の対象外。
- 疑問のマーカーは、丸だけの形から、丸に「?」に変えた。そのほうが疑問だと分かりやすい、というオーナーの指摘による。
- ToDoのタブアイコン(チェック入り)と、解決済みのマーカー(チェック入り)は似ている。タブは種類、マーカーは状態を表す場所が違うので、許容できるとClaudeは見ている。
- 形で種類を見分けられるので、色が見分けにくい人にも区別がつく([0014](0014-category-marker-colors.md) の論点に対応)。
- 見本は、iOSのネイティブ前提で描いた(オーナーの指示は「一旦」)。[0003](0003-pwa-first.md) はPWA先行なので、丸角の半透明のタブバーなどをPWAで実現できるかは、実装の前に確認が要る。
