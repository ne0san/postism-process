# 意思決定ログ

1つの決定を1ファイルで記録します。書き換えず、追記します。変えるときは新しい決定で「置き換え」ます。

## 運用ルール

- 状態は4つ: **提案 / 承認 / 却下 / 置き換え**
- 「承認」にできるのはオーナーだけ。Claudeが書くのは「提案」まで。
- 正本はこのリポジトリ。他のリポジトリのREADMEなどには、現在の結論だけを短く書いて、ここにリンクする。
- 「議論での論点」に、AI(Claude)の提案が含まれる場合はその旨を書く。

## 書式

```markdown
# 決定のタイトル

- 状態: 提案 / 承認 / 却下 / 置き換え
- 決定日: YYYY-MM-DD
- 決定者: オーナー

## 背景
## 検討した選択肢
## 決定
## 議論での論点
## 関連する未決事項
```
