# アクセント色は紫系にする

- 状態: 承認
- 決定日: 2026-11-09
- 決定者: オーナー

## 背景

[0013](0013-design-principles.md) の未決事項「アクセント色」を、11/6〜11/9のデザイン見本で比べた。[0014](0014-category-marker-colors.md) で種類ごとのマーカー色(青・橙・緑)を採る方向になったため、アクセント色は種類の色と重ならない必要がある。当初の候補(赤系 / 青〜緑系 / 黄〜オレンジ系)は種類の色とかぶるので、候補を組み直した。

## 検討した選択肢

- 紫系(ライト #7C3AED / ダーク #A78BFA)
- ピンク系(ライト #DB2777 / ダーク #F472B6)
- 無彩色(ライト #161616 / ダーク #ECECEA。黒と白をアクセントにする)

(当初の候補だった赤系、青〜緑系、黄〜オレンジ系は、種類の色とかぶるため外した)

## 決定

アクセント色は紫系(ライト #7C3AED、ダーク #A78BFA)とする。追加ボタン、「一覧」タブ、入力欄のカーソルと送信ボタンにだけ使う。種類の色(ToDo、疑問、記録)とは別枠にする。

## 議論での論点

(以下はClaudeの提案を含む)

- 候補の組み直し(紫系 / ピンク系 / 無彩色)は、Claudeの提案。オーナーは見本を見て、紫系を選んだ(「紫系いいな」)。
- 白い背景での文字と記号のコントラストは、概算で紫系が約5.7:1、ピンク系が約4.6:1。
- ダークでは少し明るい値にして、読めるようにしている。[0013](0013-design-principles.md) の原則8(ライトとダークは、それぞれの値を見て調整する)に沿う。
- 見本は、実機ではなくデザインツール上のもの。実機での見え方は未確認。
