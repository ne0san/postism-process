# クライアントはPWAを先行する

- 状態: 置き換え([0019](0019-client-cross-platform-and-web.md) で置き換え)
- 決定日: 2026-10-30
- 決定者: オーナー

## 背景

- iOSアプリの開発経験がない。
- 将来はAndroidにも展開したい([0002](0002-android-in-future.md))。
- 最初に確かめたいのは、入口の体験よりも、AIによる分類が使えるかどうか。

## 検討した選択肢

- PWA(Web)から始める
- 最初からクロスプラットフォームのネイティブアプリにする

## 決定

クライアントはPWAを先行する。

## 議論での論点

(以下はClaudeの提案を含む)

- ブラウザ向けに作れば、iOSでもAndroidでも同じ画面でまず動く。
- ウィジェットや音声入力などが欲しくなった時点で、同じAPIにつなぐ薄いネイティブの殻を足せる。
- ウィジェットとApple Watchは、クロスプラットフォームのフレームワークでも、その部分はネイティブで書く必要がある見込み(要確認)。
