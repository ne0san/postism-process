# メモはサーバー上に保存する

- 状態: 承認
- 決定日: 2026-10-28
- 決定者: オーナー

## 背景

当初の構想では、メモをiCloudなどで端末間にシームレスに同期したいと考えていた。一方で、AIによる自動分類は裏で動かしたい。

## 検討した選択肢

- iCloudなど、端末側のストアで同期する
- 自前のサーバーに保存する

## 決定

メモの正本はサーバー上に置く。

## 議論での論点

(以下はClaudeの提案を含む)

- 端末間の同期は、サーバーのAPIにつなぐだけで済む。
- iOSでもAndroidでも同じ作りにできる。
- iCloudの個人領域に置くと、サーバー側から読むのが難しく、iOSの裏処理にも制限があるため、裏での定期的な分類が成り立ちにくい。
- 電波がない場所でも書けるように、端末側で一時的に溜めて、あとで送る仕組みが必要になる。
